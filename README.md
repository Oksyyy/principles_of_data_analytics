# Principles of Data Analytics

by Oksana Abrosimova

This repository contains a Jupyter Notebook created as part of the Principles of Data Analytics study module. To demonstrate learning and understanding the core concepts, a set of tasks has been completed using the famous Iris data set.

## Required Software

- Python - Programming language required to run the code. Download from [Python.org](https://www.python.org/downloads/).
- Codespaces -  A cloud-based development environment provided by GitHub that allows running Jupyter Notebooks. Available in the repository under "Code" drop-down menu. 
- Jupyter (alternative to Codespaces) - An environment for writing and running code, exploring, analysing and visualising data. For optional installation refer to [Jupiter documenation](https://docs.jupyter.org/en/stable/install.html).

## Required Packages

All necessary packages are imported and explained within the notebook. Here's a quick overview:

- [sklearn.dataset](https://scikit-learn.org/stable/datasets/toy_dataset.html): used to load the Iris dataset from Scikit-learn’s built-in data collection. 
- [numpy](https://numpy.org/doc/stable/): used for numerical operations and data array manipulations.
- [matplotlib.pyplot](https://matplotlib.org/): used for creating plots and visualisations.
- [seaborn](https://seaborn.pydata.org/index.html): used for generating a pairplot.
- [scipy](https://docs.scipy.org/doc/scipy/index.html): used for calculation of the Coefficient Of Determination.
- [pandas](https://pandas.pydata.org/docs/index.html): used for converting numpy array into a Pandas DataFrame.
