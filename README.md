# Principles of Data Analytics

by Oksana Abrosimova

This repository contains a Jupyter Notebook created as part of the Principles of Data Analytics study. To demonstrate learning and understanding of the module's materials, a set of tasks has been completed using the famous Iris data set.

## Required Software

- Python - Programming language required to run the code. Download it [here](https://www.python.org/downloads/)
- Codespaces -  A cloud-based development environment provided by GitHub that allows running Jupyter Notebooks. Codespaces is available from Github directory, under "Code" drop-down menu 
- Jupyter (alternative to Codespaces) - a computational notebook that provides environment to write and run code, explore, analyse and  visualise data. For option installation refer to Jupiter documenation: [Jupiter](https://docs.jupyter.org/en/stable/install.html)

## Required Packages

All necessary packages are imported and explained within the notebook. Here's a quick overview:

- [sklearn.dataset](https://scikit-learn.org/stable/datasets/toy_dataset.html): used to load the Iris dataset from Scikit-learn’s built-in datasets 
- [numpy](https://numpy.org/doc/stable/): used for numerical operations and creating arrays for data visualisations
- [matplotlib.pyplot](https://matplotlib.org/): used for creating plots and other data visualisations
- [seaborn](https://seaborn.pydata.org/index.html): used for generaiting a pairplot
- [scipy](https://docs.scipy.org/doc/scipy/index.html): used for calculation of Coefficient Of Determination
- [pandas](https://pandas.pydata.org/docs/index.html): used for converting numpy array into a Pandas DataFrame
